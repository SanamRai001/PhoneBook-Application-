# Phone Book Application

A small **Python command-line contact manager** that stores contacts in JSON and supports the core phone-book workflow.

## Features

- add a contact
- search by name
- list contacts
- update a phone number
- delete a contact
- basic name and phone validation
- JSON-file persistence
- simple tests in `test_project.py`

## How it works

```text
CLI command
   ↓
validation
   ↓
add / search / update / delete
   ↓
phonebook.json
```

## Run

```bash
python project.py
```

## What I learned

This was a focused practice project for Python functions, loops, validation with regular expressions, file handling, JSON serialization, and small testable units.
